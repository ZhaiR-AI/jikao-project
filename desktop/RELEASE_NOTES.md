这是 Windows 10/11 x64 便携试用版，自带 Python 运行环境。使用者不需要安装 Python、Codex 或输入命令。

> **模型要求：导入卷子必须使用支持图片输入和文字识别的多模态大模型（视觉模型）。** 软件会把 PDF 页面转成图片交给模型识别。纯文字聊天模型、只能生成图片的模型都不适用；请确认模型平台的 API 也支持图片输入。

v0.1.2 将这项要求明确标在启动窗口、使用说明和模型配置教程开头。此前 v0.1.1 的真实试卷验证范围见下文。

下载 Assets 中的 **Chengkao-Windows-x64-….zip**，右键“全部解压”，直接解压到桌面等较短路径，再双击 **启动成考助手.exe**。不要下载名为 Source code 的源码包，也不要在压缩包内直接运行。若提示路径过长或无法提取文件，请换到更短目录重新完整解压，不要跳过错误。

本版包含 v0.1.1 根据真实试卷测试完成的修复：保留作文题目、字数要求和编号提纲，不再把提纲误当作多道题；识别带“☞”等装饰符号的阅读标题；检测旧版本遗漏的作文题目并提示重新整理。旧卷如提示问题，可在页面点击“重新整理异常部分”，原卷和原作答记录保留。

首次启动，在中文窗口填写模型平台提供的接口地址、模型名称和 API Key，点击“保存配置并启动”。以后再次打开时自动载入配置并启动网页。

- 必须使用支持图片输入和文字识别的多模态大模型；模型平台需支持 OpenAI 兼容的 Chat Completions 接口及图片输入。
- 模型账号和额度由用户自行提供。生成、识别和判卷可能产生模型费用。
- 数据保存在 `程序文件/app/data`，配置在 `程序文件/app/models.json`。更新前停止程序并备份；解压新版本后，把自己的数据和配置复制到新版本的相同位置。
- 关闭启动窗口会停止服务，关闭前请保存作答并等待生成、判卷完成。
- 初始软件包不包含私人卷子、真实密钥和学习记录。
- 本试用包尚未进行商业代码签名，Windows 可能提示未知发布者，请核对来源和 SHA-256 文件，不要关闭系统防护。

v0.1.1 按新手流程实测了发布页下载、解压、启动窗口填写真实模型配置、导入真实 5 页 PDF、生成 54 道题、保存并恢复 54 道实际作答、调用真实模型判卷并刷新查看成绩。测试未模拟模型响应。修复后的重新导入通过了试卷完整性检查；旧卷的“重新整理异常部分”也已验证。v0.1.2 补充模型要求提示，未改动识别和判卷逻辑。

测试使用现有 Windows 电脑上的隔离便携副本，并从启动进程的 PATH 移除了系统 Python。已验证的模型账号只有一个，未覆盖新用户注册、充值流程，也未覆盖所有模型平台或全新 Windows 电脑。AI 评分不等于权威答案；当前继续作为试用版发布。
