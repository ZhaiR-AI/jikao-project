> **PDF 必须使用支持图片输入和文字识别的 VL 多模态大模型。** v0.1.3 对每一页 PDF 都进行图片识别，不再用内嵌文字层跳过识别。模型平台的 API 也必须支持图片输入。

v0.1.3 修复了真实四级试卷中，PDF 内嵌文字乱码导致漏题、题干不完整及分值异常的问题。旧版生成不完整的卷子可以点击“重新整理异常部分”，程序会用页面图片重新识别旧文字层结果，生成修正版并保留原卷与作答。

- 支持 PDF、Word（.docx）、TXT、Markdown。非 PDF 文档先读取文字，再由大模型整理；Word 中的图片、公式对象或复杂自动编号请先导出为 PDF，旧版 .doc 请另存为 .docx 或 PDF。
- 整理结果必须是完整 JSON；模型返回被截断时重试相应部分，不再把内部某一道题误当成整份结果。
- 完整性检查增加缺失题干、仅有占位题干及旧 PDF 文字层结果提示。
- 四级卷按 100 分练习权重展示：作文 15、听力 35、阅读 35、翻译 15。原 PDF 的听力如果只有选项，问题在配套音频中，软件会明确提示，不编造题干。
