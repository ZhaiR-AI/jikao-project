这是 Windows 10/11 x64 便携试用版，自带 Python 运行环境。使用者不需要安装 Python、Codex 或输入命令。

下载 Assets 中的 **Chengkao-Windows-x64-….zip**，右键“全部解压”，双击 **启动成考助手.exe**。不要下载名为 Source code 的源码包，也不要在压缩包内直接运行。

首次启动，在中文窗口填写模型平台提供的接口地址、模型名称和 API Key，点击“保存配置并启动”。以后再次打开时自动载入配置并启动网页。

- 模型平台需支持 OpenAI 兼容的 Chat Completions 接口，模型需支持图片输入。
- 模型账号和额度由用户自行提供。生成、识别和判卷可能产生模型费用。
- 数据保存在 `程序文件/app/data`，配置在 `程序文件/app/models.json`。更新前停止程序并备份；解压新版本后，把自己的数据和配置复制到新版本的相同位置。
- 关闭启动窗口会停止服务，关闭前请保存作答并等待生成、判卷完成。
- 初始软件包不包含私人卷子、真实密钥和学习记录。
- 本试用包尚未进行商业代码签名，Windows 可能提示未知发布者，请核对来源和 SHA-256 文件，不要关闭系统防护。

自动检查覆盖自带运行环境的导入、实际启动、页面和空数据接口访问以及服务关闭。并不代表已在所有用户电脑上测试，也没有使用真实付费模型验证整卷生成和判卷。

遇到问题请提交 Issues，说明系统版本、操作步骤和错误提示。日志或截图分享前请检查并遮住个人信息及密钥。
