## Windows 便携版补充检查

- 使用官方 Python 3.12.10 x64 嵌入式运行时，将依赖与许可信息一起打包，并编译原生中文 EXE 启动器。
- 从测试进程 PATH 移除系统 Python，并清除 PYTHONHOME/PYTHONPATH 后，通过包内 EXE 实际启动服务；试卷页、学习页、错题本和卷子列表请求成功，服务可正常关闭。
- 配置窗口的接口地址、模型名称和密钥可以保存并重新读取；密钥默认隐藏，覆盖配置时保留本地备份。
- 检查了中文窗口布局；未使用真实 API 密钥调用模型。
- GitHub Actions 会在发布标签触发时重建便携包，并使用包内 EXE 运行启动检查，成功后才上传 Release 附件。

本地验证使用的是已有 Windows 电脑上的隔离进程，不是全新 Windows 虚拟机。尚未覆盖所有用户电脑，也未进行商业代码签名。

## 源码版检查

- 运行 `install.ps1` 创建虚拟环境、下载依赖并生成配置文件。
- 使用 `constraints.txt` 中记录的版本重复安装，保留修改后的 `models.json`、`.env` 和 `data` 内的测试文件。
- `pip check` 未发现依赖冲突。
- 试卷、学习、错题本页面及前端 JavaScript 的 HTTP 请求返回成功。
- 空数据状态的卷子列表、最近生成任务、错题和回收站接口返回成功。
- 非 PDF 上传被拒绝。
- 用临时合成的一页 PDF 验证转图片流程成功。
- README 中的最小模型配置可加载，default 和 vision 别名解析正确。
