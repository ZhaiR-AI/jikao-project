## v0.1.1：真实试卷与新手流程复测

测试从 GitHub 的 v0.1.0 发布页开始，下载实际 ZIP 并核对 SHA-256，阅读包内使用说明，在隔离目录中运行。首次启动不带已有卷子或配置，通过真实启动窗口填写已有模型账号的三项信息。测试进程的 PATH 不包含系统 Python。浏览器使用 Edge，操作真实页面，没有拦截网络请求、替换模型响应或编造题目、答案。

发现并修复：

- Windows 深层目录解压可能超过路径长度限制。发布页、README、包内说明新增短路径解压和完整重新解压指引。
- 真实作文题的编号提纲被误当作题号，同时遗漏了作文主题与字数要求。现在保留完整要求，并检测旧卷遗漏的作文主题。
- OCR 产生的装饰符号阅读标题未被识别。现在接受这类标题，避免不必要的模型提取和不完整结果。
- 启动器生成的模型配置备份和临时文件纳入 Git 忽略规则。

修复后已验证：

- 使用真实试卷汇编中的连续 5 页原卷，重新通过网页上传并调用真实视觉模型，约 38 秒生成 54 道题，完整性状态为 ready。
- 对已有异常生成结果点击“重新整理异常部分”，成功得到 54 道题并通过完整性检查，旧卷保留。
- 通过网页逐题填写既有学习记录中的 54 道真实作答，保存、刷新后内容一致。
- 通过“提交并 AI 判卷”实际调用模型，约 49 秒收到成功响应，返回 54 道题的结果，页面显示 75.5 分，刷新可恢复成绩。该分数仅用于验证结果保存和显示，不代表人工核准的评分准确性。
- 点击启动器“停止服务”后，服务进程和监听端口退出；关闭后重新打开 EXE 自动加载配置，54 道作答、一次判卷记录、75.5 分和 16 条错题仍在。重开后的试卷和错题页无 JavaScript 异常。
- 原来运行中的服务持续可访问；原目录 26 个学习记录文件的 SHA-256 与测试前一致。
- 使用真实历史 OCR 复查另外几份原卷，五份试卷的题目数均保持 54；其中一份仍有待人工核对提示，因此未把所有历史卷宣称为完全通过。

真实 PDF、答案、模型凭证、运行数据和带个人内容的截图仅留在本地，不随源码或 ZIP 发布。一次真实模型成功不代表所有供应商兼容，也不代表所有试卷格式均能准确识别。尚未以新客户身份测试模型平台注册和充值，尚未在另一台电脑或全新 Windows 虚拟机验证。
