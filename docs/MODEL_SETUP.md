# 第一次使用：模型配置教程

你不需要会编程，也不需要安装 Codex。按照下面的步骤，把模型平台提供的三项信息填进项目即可。

本教程适用于 Windows 本地版。推荐先从 [软件下载页](https://github.com/ZhaiR-AI/jikao-project/releases) 下载便携 ZIP，全部解压后双击“启动成考助手.exe”。便携版不需要安装 Python；只有下载源码版的用户，才需要按 [首页安装教程](../README.md) 安装 Python 并运行 `install.bat`。

## 先弄清楚：模型平台是什么？

本软件负责显示卷子、记录作答和管理错题；识别 PDF、整理试题和 AI 判卷需要调用模型服务。你需要使用自己注册的模型平台账号，费用和额度由该平台管理。

你平时使用的 AI 聊天网页账号或聊天会员，不能直接当作本软件的模型配置。请确认平台另外提供 **API 服务**，并为 API 开通了可用额度。

可以把下面三项理解为：

| 要找的信息 | 简单理解 | 平台上可能使用的名称 |
| --- | --- | --- |
| 接口地址 | 软件把请求发到哪里 | Base URL、API 基础地址、兼容接口地址 |
| 模型名称 | 让哪个模型处理卷子 | Model ID、模型 ID、API 调用名称 |
| API Key | 允许软件使用你的模型额度的密钥 | API 密钥、API Keys、访问令牌 |

这三项必须来自同一个平台、同一个可用的调用方案，不要混用不同平台的信息。

## 1. 注册一个符合要求的模型平台

在你选择的平台官方网站注册账号，进入它的“开发者平台”或“控制台”。不同平台页面名称不同，本教程不指定某一家服务商，也不承诺某个平台一定免费。

选用的平台和模型要同时满足：

- 提供兼容 OpenAI **Chat Completions** 的接口。
- 所选模型支持在对话中接收图片，也常叫“视觉模型”或“多模态模型”。本项目会把 PDF 页面转成图片交给模型识别。
- 你的账号有调用这个模型的权限和可用的 API 额度。

只有文字聊天功能的模型不适合完整的 PDF 识别流程；只支持生成图片的模型也不适合这里的用途。配置里的 `supports_vision: true` 不能让一个不支持图片的模型获得识图能力。

拿不准时，可以直接复制下面这段话问平台客服：

> 我要在本地试卷软件中使用模型。软件通过 OpenAI 兼容的 Chat Completions 接口发送文本和 image_url 图片输入。请提供你们支持图片识别的模型 ID、API Base URL、API Key 获取方法，并确认我这个账号是否有调用权限、额度以及计费标准。

软件本身在电脑上运行，但使用 AI 功能时会把相关试卷页面、题目或作答内容发给你配置的模型平台处理。

## 2. 获取三项信息

在平台控制台或它的接口文档中，分别找到：

1. **API Key**：通常在“API 密钥”页面创建。复制并妥善保存，不要把它当作登录密码，也不要发给别人。
2. **Base URL**：使用平台说明的 API 基础地址。它可能以 `/v1` 或其他兼容路径结尾，以平台文档为准。
3. **模型 ID**：复制文档里的准确调用名称，保留大小写和版本后缀。不要只填写聊天网页显示的昵称。

不要把平台首页、聊天页面地址填成 Base URL，也不要把完整的 `/chat/completions` 请求地址填进去。

先确认 API 额度可用；如果需要充值，了解计费方式并设置自己能接受的预算后再使用。导入长卷和反复生成通常会增加调用量。

## 3. 在启动窗口填写（便携版推荐）

双击“启动成考助手.exe”，把上述三项信息填入对应输入框，然后点击“保存配置并启动”。密钥默认隐藏，软件会自动保存配置并打开网页。你不需要手动修改任何文件。

下次使用直接双击 EXE 即可。更换模型时修改输入框，再点“保存配置并启动”；如果服务已经运行，会提示先保存作答并等待任务完成，再重启。继续阅读第 5 步验证是否成功。

### 使用源码版时：打开配置文件

1. 打开你解压后的项目文件夹，就是能看到 `install.bat` 和 `start.bat` 的地方。
2. 找到 **models.json**。如果没有这个文件，先双击 `install.bat` 并确认安装成功。
3. 右键 `models.json` → “打开方式” → “记事本”。

请修改 `models.json`，不要修改旁边的 `models.example.json`，后者只是模板。源码版的网页没有模型设置入口，也不需要在 `.env` 中重复填写这些信息。便携版使用独立的中文启动窗口来配置。

## 4. 源码版：只替换这三处（便携版跳过）

首次安装生成的文件中，找到下面三行：

```json
"model": "REPLACE_WITH_YOUR_VISION_MODEL",
"base_url": "https://your-model-provider.example/v1",
"api_key": "REPLACE_WITH_YOUR_API_KEY"
```

把英文双引号**里面的内容**替换成你自己的三项信息：

| 文件中的位置 | 填什么 |
| --- | --- |
| `model` | 平台给你的真实模型 ID |
| `base_url` | 平台给你的 API 基础地址 |
| `api_key` | 你在平台创建的 API Key |

不要修改 `my-vision-model`，它是程序内部使用的别名。`default`、`fallback`、`fast`、`vision`、`channel`、`type`、`supports_vision` 都保持首次安装时的内容即可。

替换后按 **Ctrl+S** 保存。不要删除英文双引号、括号和逗号；最后一项 `api_key` 的值后面不加逗号。上面的三行只是定位用的片段，不能用它们替换整个文件。

如果使用“另存为”，选择 UTF-8 编码，并确保文件名仍是 `models.json`，不是 `models.json.txt`。在 Windows 资源管理器的“查看”菜单中打开“文件扩展名”，可以检查完整名称。

不要把真实配置文件提交到 GitHub；截图或求助时遮住整个 API Key。密钥如已泄露，应在平台控制台撤销并重新创建。

## 5. 启动并验证

**便携版：**点击启动窗口的“保存配置并启动”，网页会自动打开。它使用空闲端口，地址显示在启动窗口中，不一定是 8020。浏览器关闭后，可以点“打开页面”再次访问。

**源码版：**按下面的第 1～3 步启动。两种版本都从第 4 步开始用小 PDF 验证。

1. 如果程序正在运行，在原来的启动窗口按 **Ctrl+C** 停止，再重新双击 `start.bat`。修改配置后需要重启。
2. 等待窗口显示访问地址，保留这个窗口。
3. 在浏览器打开 **http://127.0.0.1:8020/exam**。
4. 选择一份**只有一页、题目完整、文字清晰的小 PDF**，点击“生成试卷”。尽量先用几道完整选择题，避免用长卷中被截断的一页。
5. 能识别出题目并生成试卷，说明这次识别和生成流程能够使用当前模型服务。
6. 尝试作答并提交判卷，确认判卷也能完成，再处理更多卷子。

这些步骤会实际调用你配置的模型，可能产生费用。仅仅能打开网页，并不能证明模型配置成功。识别或判卷能完成也不代表答案一定正确，请核对原卷。

## 出错时怎么处理

| 错误或现象 | 先检查什么 |
| --- | --- |
| `401`、`Unauthorized`、密钥无效 | API Key 是否复制完整、是否已失效，以及是否与 Base URL 属于同一平台。 |
| `403`、没有权限 | 账号是否开通 API、是否有该模型的访问权限，或平台是否限制了当前请求。 |
| `404`、模型不存在 | Base URL 是否填写正确、是否误加了 `/chat/completions`；模型 ID 是否与文档完全一致。 |
| `429`、额度不足、请求过多 | 到平台查看具体错误、余额及调用限制；有余额也可能触发频率限制，可稍后重试。 |
| 不支持图片、`image_url` 相关错误 | 该模型及其兼容接口是否支持图片输入。换用平台确认支持的视觉模型。 |
| `JSONDecodeError`、配置无法解析 | 是否误删了引号或逗号，是否使用中文引号，是否改错了文件。 |
| 超时、连接失败 | 当前网络能否访问服务商接口、Base URL 是否正确、服务商是否发生故障。 |
| 生成失败，但没有上面的明确错误 | 不一定是配置问题。也可能是 PDF 内容不清晰、题目被截断或模型输出不符合要求；先用小 PDF 验证。 |

若仍然无法解决，反馈时提供“平台名称、模型 ID、错误提示、操作步骤”即可。截图前遮住密钥和个人内容，不要发送真实的 `models.json` 或整份私人试卷。

## 已经配置成功，以后怎么用？

便携版以后双击“启动成考助手.exe”即可；源码版双击 `start.bat` 并打开本地网页。不用每次重新配置。更换模型平台、模型或密钥后，需要保存配置并重启。

便携版的试卷和学习记录在 `程序文件/app/data`，可点击启动窗口的“数据目录”打开，配置在 `程序文件/app/models.json`；源码版在项目根目录的 `data` 和 `models.json`。更新软件时请按 [首页的备份与更新说明](../README.md) 操作，保留自己的数据和配置。
